# NDE 文件命名规则

命名格式：`{纤维类型}_{基体类型}_{结构}_{检测方法}_{缺陷类型}_{型号}_{时间戳}.nde`

---

## 纤维类型

| 缩写 | 含义 |
|------|------|
| CF | 碳纤维 |
| GF | 玻璃纤维，石英纤维 |
| BF | 硼纤维 Boron |
| AF | 芳纶纤维 Aramid |
| C/SiC | 碳/碳化硅 |

## 基体类型

| 缩写 | 含义 |
|------|------|
| EP | 环氧 Epoxy |
| BMI | 双马 BMI |
| PI | 聚酰亚胺 Polyimide |
| TP | 热塑 Thermoplastic（PEEK PPS） |
| SiC | 碳化硅 |

## 结构

| 缩写 | 含义 |
|------|------|
| Plate | 平板（RTM、RFI） |
| Taper | 变厚度平板 |
| RZone | R区 |
| BondPP | 板板胶接 Plate-Plate bonding |
| BondSC | 板芯胶接 Skin-Core bonding |
| Hybrid | 混杂铺层 |

## 检测方法

| 缩写 | 含义 |
|------|------|
| WRUT | 水耦合反射水膜/水浸单探头 Water |
| WPUT | 水穿透 |
| DBUT | 延迟块耦合单探头 Delay block |
| PAUT | 相控阵 |
| AUT | 空耦 AirUT |
| LUT | 激光 LaserUT |

## 缺陷类型

| 缩写 | 含义 |
|------|------|
| OK | 好区 |
| Dl | 分层 Delamination |
| Db | 脱粘 Debonding |
| Po | 孔隙 Porosity |
| Ap | 胶膜孔隙 Adhesive-film porosity（胶接结构中胶膜内的孔隙） |
| Vo | 气孔 Void |
| In | 夹杂 Inclusion |
| Fb | 纤维相关 Fiber-related（纤维屈曲、纤维褶皱） |
| Rs | 树脂相关 Resin-related（富脂、贫胶） |
| Cp | 耦合不良 Coupling-related（探头耦合不充分、水膜异常等） |
| Uc | 不可识别 Unclassified |


## 数据集实际材料分布（已扫描）

基于 `dataset/` 下全部 1,902 个 `.nde` 文件的 `Private/MaterialInfo` 元数据 + 文件名扫描统计（2026-08-26）。

### 纤维类型与纤维牌号对应关系

| 纤维类型 | 含义 | 属于该类型的纤维牌号 | 文件数 |
|------|------|------|------|
| GF | 玻璃纤维 | QW280、QW120 | 1,423 |
| CF | 碳纤维 | ZT9H、CF8611 | 446 |
| GFAF | 玻纤/芳纶混杂 | FQW199 | 33 |

### 基体类型与基体牌号对应关系

| 基体类型 | 含义 | 属于该类型的基体牌号 | 文件数 |
|------|------|------|------|
| EP | 环氧 | 1316、AC319、5224A、AC531 | 1,902 |

**说明：**
- 纤维牌号 `QW280`/`QW120` 属 GF（玻纤纱），`ZT9H`/`CF8611` 属 CF（碳纤维），`FQW199` 属 GFAF（玻纤/芳纶混杂）。
- 全部文件基体均为 EP，牌号 `1316` 占多数（1,605 个），其余为 `AC319`（251）、`5224A`（33）、`AC531`（13）。
- 牌号与类型一一归属，无跨类。

### 材料体系与型号（按文件名解析）

文件名格式：`{纤维}_{基体}_{结构}_{方法}_{缺陷}_{型号}_{时间戳}_{纤维牌号}_{基体牌号}.nde`，型号取第 6 段（Z109 / Z409）。

| 纤维牌号/基体牌号 | 纤维类型 | 型号 | 结构 | 文件数 | 体系描述 |
|------|------|------|------|------|------|
| QW120/1316 | GF 玻璃纤维 | Z109 | BondPP、Plate | 475 | 玻纤织物/高温环氧 |
| QW280/1316 | GF 玻璃纤维 | Z109 | BondPP、Plate | 464 | 玻纤织物/高温环氧 |
| ZT9H/1316 | CF 碳纤维 | Z109 | BondPP、Plate | 433 | 碳纤维织物/高温环氧 |
| QW280/AC319 | GF 玻璃纤维 | Z109 | Plate | 251 | 玻纤织物 |
| QW280/1316 | GF 玻璃纤维 | Z409 | Plate | 233 | 玻纤织物/高温环氧 |
| FQW199/5224A | GFAF 玻纤/芳纶混杂 | Z409 | Plate、Taper | 33 | 玻纤芳纶混杂织物/高温环氧 |
| CF8611/AC531 | CF 碳纤维 | Z409 | Plate | 13 | 高温环氧/碳纤维织物 |

> **注**：`QW280/1316` 同时存在 Z109 与 Z409 两个型号——Z109 覆盖 BondPP、Plate 两种结构（464 个），Z409 仅 Plate（233 个）。Z109 系列合计 1,623 个文件，Z409 系列合计 279 个文件。
